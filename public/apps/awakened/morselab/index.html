Morse Lab

A precise Morse code translator for Android. Translate and decode Morse, hear it as a real CW tone or telegraph sounder, and learn with a built-in Morse chart.

Get it on Google Play

Translate both ways

  • Text to Morse live as you type
  • A forgiving decoder for Morse to text
  • Prosigns like <SK>, <AR> and <BT>, plus accented letters

Hear it right

  • Clean CW tone or telegraph sounder
  • 5–60 WPM with Farnsworth spacing
  • "PARIS" timing, exact to the audio sample

Learn Morse code

  • Searchable Morse chart: tap any code to hear it
  • Guides to prosigns, timing and learning by sound
  • The history of Morse code

Export

  • Copy, share or save the Morse as text
  • Save the audio as a WAV file

Private by design

  • Works fully offline
  • No account, ads, analytics or tracking
  • No permissions requested
