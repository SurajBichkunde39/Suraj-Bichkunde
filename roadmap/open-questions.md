# Open questions

Answers to these will sharpen the plan. Rough answers are fine — write them
inline under each question, then fold anything important into
`planning.md` / `roadmap.md` and delete the question.

## About time and energy

1. **How many hours a week can you realistically give this**, outside work?
   (The plan currently assumes ~4–6 hrs/week: ~45 min on most weekdays plus a
   bit on the weekend. If it's 2 hrs, seasons get fewer milestones; if it's 10,
   they get more.)
2. **When in the day do you have the most energy?** Morning before work,
   evening, weekends?
3. **Any fixed busy periods** in the next 6 months (travel, festivals, release
   crunches, on-call)?

## About direction

4. **Where do you want to be in 2–3 years?** None of these is wrong, and it's
   fine to say "not sure yet" — but the answer changes the weighting:
   - Staff/Principal **mobile** engineer (depth + cross-platform breadth)
   - **Product engineer** who can build a whole feature/product alone
   - **AI engineer** building AI features and agents
   - Engineering **manager / tech lead** path
   - Your own **product / indie business** (your Play Store apps hint at this)
5. **What does the TCGPlayer mobile stack look like?** Native iOS + Android?
   KMP? React Native / Flutter? This decides how the iOS lane is shaped.
6. **Does your team at eBay use AI coding tools** (and which)? If so, lane 01
   can lean on work time.

## About resources

7. **Budget** for paid things? Examples: Apple Developer account ($99/yr,
   needed for TestFlight/App Store), a cloud bill (~$5–20/month is enough for
   S3), a course or two, an AI coding tool subscription.
8. **Do you have a Mac** for iOS work?
9. **Preferred cloud**, if any (AWS vs GCP vs Azure)? Default proposal is GCP
   Cloud Run for simplicity — or whatever eBay uses, if that's knowable.

## About this system

10. **Should any of this be public?** This repo hosts your public site. Right
    now `roadmap/` sits outside `src/`, so it's in the GitHub repo but *not*
    on the website. Options: keep it as is; render a "Now / Learning" page on
    the site (good for learning-in-public); or move it to a private repo.
11. **Is SDUI Lab the right spine project?** Or is there something you'd
    rather build — e.g. growing Quiet or Morse Lab into something bigger?
12. **What did I miss?** Anything on your mind that isn't a lane yet?
