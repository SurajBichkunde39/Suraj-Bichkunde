# Log

The memory of the journey. Copy from [`../templates/`](../templates/).

Naming:

- Weekly: `YYYY-Www.md` (ISO week), e.g. `2026-W44.md`
- Monthly retro: `YYYY-MM-retro.md`, e.g. `2026-11-retro.md`
- Season review: `season-N-review.md`, e.g. `season-1-review.md`

Keep entries short. A one-line day is a good day. The log isn't for anyone
else — it's so the monthly retro and season review have something real to
look back on.
